# UI and UX direction

- Keep the app focused on assessment entry, assessment history, and subject-wise comparisons.
- Ask for the exam name/date, subject count, and one maximum mark value for the assessment.
- Prefill every known subject automatically. Increasing the subject count adds blank rows for new subjects.
- Show one row per subject for the subject name and obtained marks.
- Show percentages beside marks and label CGPA as an estimate on a 10-point scale.
- Validate missing values and invalid marks. Never assume a maximum or treat missing marks as zero.
- Keep the layout keyboard-operable and usable on desktop, tablet, and phone.
- Explain browser-local persistence. Do not imply cloud backup or official institutional grading.
